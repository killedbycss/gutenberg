# GutenbergMac

Нативное приложение для macOS, полностью построенное на SwiftUI.

## Требования

- macOS 13 или новее
- Xcode 16 или новее
- Swift 6

## Запуск из Xcode

Откройте `Package.swift` в Xcode, выберите схему `GutenbergMac` и нажмите Run.

## Приложения для запуска двойным кликом

Дважды кликните по `build-apps.command`. Скрипт создаст в папке `dist` две
независимые версии приложения:

- `Gutenberg Intel.app` — только для Intel (`x86_64`)
- `Gutenberg Apple Silicon.app` — только для Apple Silicon (`arm64`)

Обе версии используют иконку из `studio/app-icon.iconset` и получают локальную
ad-hoc подпись. Готовое приложение можно запускать двойным кликом или перенести
в папку «Программы».

## Поддерживаемые Mac

Исходный проект поддерживает обе стандартные архитектуры macOS:

- Apple Silicon (`arm64`)
- Intel (`x86_64`)

Скрипт `build-apps.command` намеренно выпускает отдельное приложение для каждой
архитектуры.
