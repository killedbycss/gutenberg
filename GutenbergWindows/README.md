# Гутенберг для Windows 11

Самостоятельное нативное приложение на C# и WinUI 3. Все четыре инструмента работают в одном окне: **Орфография**, **Типограф**, **Конвертер** и **Макеты**. React-интерфейсы и браузер приложению не нужны.

## Получение готовой папки

На Windows 11 установите Visual Studio 2022 с workload **.NET Desktop Development**, .NET 8 SDK и Git. Затем откройте PowerShell в этой папке:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\Packaging\build.ps1 -Architecture x64
```

Скрипт загружает официальный Python Embedded, устанавливает локальные зависимости и выполняет self-contained публикацию. Готовую папку можно перенести на другой компьютер с Windows 11: устанавливать Python, Node.js или .NET там не требуется. Для ARM64 используйте `-Architecture arm64`.

Запускаемый файл: `GutenbergWindows.exe` в показанной скриптом папке `publish`.

## Разработка

Откройте `GutenbergWindows.csproj` в Visual Studio. Перед первым запуском один раз выполните `Packaging\build.ps1`; это подготовит папку `Runtime`. Пользовательский словарь и журнал ядра хранятся в `%LOCALAPPDATA%\Gutenberg`.

Орфография по умолчанию использует публичный LanguageTool, поэтому для неё нужен интернет. Остальные инструменты работают локально. Адрес собственного LanguageTool можно передать переменной окружения `LT_URL`.

## Архитектура

- UI целиком реализован стандартными контролами WinUI 3.
- Встроенное локальное ядро запускается скрыто на `127.0.0.1:8770` и завершается вместе с приложением.
- В `BackendRoot` лежит независимая копия исходников всех четырёх модулей.
- Итоговая публикация включает Windows App SDK, .NET runtime, Python Embedded и Python-зависимости.
