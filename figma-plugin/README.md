# Гутенберг для Figma

## Установка для разработки

1. Figma Desktop → Plugins → Development → Import plugin from manifest.
2. Выбрать `figma-plugin/manifest.json`.
3. Запустить «Гутенберг» из Development plugins.

Плагин не заменяет Pages-версию. Вкладка «Весь Gutenberg» сохраняет доступ ко
всем существующим модулям, а «На холсте» создаёт редактируемые слои Figma.

Нативный режим сейчас умеет:

- создавать редактируемый макет из `FrameNode` и `TextNode`;
- создавать единое Бенто 4×3 с разным цветом и текстом в каждом блоке;
- помещать палитру на холст;
- применять базовую типографику к выделенным текстовым слоям;
- экспортировать выделение в PNG и SVG;
- экспортировать верхнеуровневый Motion-фрейм в GIF в поддерживающей это версии Figma.

Полные Орфограф, Типограф, Конвертер, Макеты и Бенто доступны во встроенной
Pages-вкладке. Это переходный совместимый режим: по мере вынесения общего ядра
его команды будут получать нативные операции над выделением без удаления
веб-варианта.

## Ограничение шрифтов

Плагин использует шрифт, доступный редактору Figma. Загруженный в веб-интерфейс
файл можно применять в превью и экспорте, но для редактируемого `TextNode` этот
шрифт должен быть установлен локально или предоставлен организацией Figma.
