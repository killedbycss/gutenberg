# Гутенберг для GitHub Pages

Эта папка генерируется командой `bash studio/build-pages.sh`. Главный
`index.html` и `.nojekyll` находятся в корне репозитория, а здесь хранятся
ресурсы и собранные модули (`assets/` и `app/`).

В настройках репозитория GitHub откройте **Settings → Pages**, выберите
**Deploy from a branch**, нужную ветку и папку, в которой лежит этот `index.html`.
Все пути относительные, поэтому сайт работает как в корне, так и по адресу
вида `https://имя.github.io/репозиторий/`. Для публикации выберите корень
ветки (`/(root)`), а не папку `github-pages`.

Орфография обращается напрямую к публичному LanguageTool и требует интернет.
Остальные вычисления выполняются локально в браузере; загруженные файлы не
отправляются на сервер.
