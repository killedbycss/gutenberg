# LanguageTool — проверка орфографии (онлайн)

Вкладка **«Орфография»** проверяет текст через **LanguageTool** онлайн. Ничего
устанавливать не нужно — **ни Docker, ни Java**: «словарь» подгружается онлайн,
нужен только **интернет**.

Архитектура прежняя: React-фронтенд → Flask-бэкенд → HTTP к REST API LanguageTool
(`/v2/check`). По умолчанию адрес — публичный сервис `https://api.languagetool.org`.

Без интернета «Типограф», «Конвертер» и «Макеты» всё равно работают; во вкладке
«Орфография» будет подсказка про соединение.

---

## Как это работает

- По умолчанию запросы идут на `https://api.languagetool.org` (бесплатный публичный
  сервис). Есть лимиты на объём (примерно 20 КБ текста за запрос и несколько запросов
  в минуту) — для обычной вычитки этого хватает.
- Текст отправляется на сервер LanguageTool (это онлайн-сервис). Если нужна
  **приватность или офлайн** — поднимите свой сервер LanguageTool и укажите его адрес:

  ```bash
  LT_URL=http://localhost:8010 studio/start.command
  ```

  Свой сервер можно запустить как угодно (в т.ч. через `docker-compose.yml` рядом) —
  это уже по желанию, не требование.

---

## Если проверка не работает

| Симптом | Что делать |
|---|---|
| Баннер «нет связи с сервисом» | Проверьте интернет и обновите страницу |
| «Превышен лимит» | Публичный сервис ограничивает частоту — подождите минуту, или поднимите свой сервер и задайте `LT_URL` |
| Нужна приватность | Задайте `LT_URL` на локальный сервер — текст не будет уходить наружу |

---

## Где это в коде

`spellcheck/backend/config.py` — адрес `LT_URL` (по умолчанию онлайн-сервис).
`spellcheck/backend/languagetool_client.py` — тонкий HTTP-клиент к `/v2/check`.
Разбор ответа и подсветка ошибок не зависят от того, онлайн это или свой сервер.
