# Модуль проверки орфографии и грамматики (RU / EN)

Проверка и исправление орфографии, грамматики и пунктуации для русского и
английского текста. Интерфейс в стиле Google Docs: подчёркивание ошибок прямо
по мере ввода и попап с вариантами, каждый из которых можно **принять** или
**отклонить**.

- **Бэкенд:** Flask (тонкая обёртка над self-hosted LanguageTool)
- **Фронтенд:** React + Vite
- **Движок:** [LanguageTool](https://languagetool.org/) в Docker — работает
  **полностью офлайн**, текст никуда не уходит.

---

## Принятые решения

| Вопрос | Решение |
|---|---|
| Движок | **LanguageTool** — открытый, покрывает орфографию + грамматику + пунктуацию для RU и EN сразу, отдаёт ошибки с позициями и вариантами |
| Развёртывание | **Self-hosted / офлайн** через Docker (по умолчанию `localhost:8010`) |
| Стиль | Базово — орфография/грамматика/пунктуация; **тумблер «Проверять стиль»** включает канцеляризмы, тавтологию и т.п. |
| Термины / имена собственные | **Пользовательский словарь исключений** (кнопка «+ В словарь» и панель управления) |
| Режим | **Реальное время** с debounce 550 мс |
| Формат ответа | **Список ошибок с позициями** (`offset`/`length`) и вариантами замен |
| Языки | **Автоопределение + ручной выбор** RU/EN; RU и EN в одном документе распознаются одновременно |

## Архитектура

```
┌────────────────┐      /api/check          ┌───────────────┐   /v2/check   ┌───────────────┐
│  React (Vite)  │  ───────────────────────▶ │  Flask API    │ ────────────▶ │ LanguageTool  │
│  :5173         │ ◀─── список ошибок ─────── │  :5001        │ ◀──────────── │  :8010 (Docker)│
│  редактор+попап│      с позициями          │ + словарь     │   матчи       │  офлайн        │
└────────────────┘                           └───────────────┘               └───────────────┘
```

Flask добавляет к «сырому» LanguageTool три вещи: **классификацию** ошибок по
типам (орфография/грамматика/пунктуация/стиль), **фильтр по стилю** (через
`disabledCategories`) и **пользовательский словарь исключений**.

## Быстрый старт

Нужны: **Docker**, **Python 3.10+**, **Node 18+**.

### 1. LanguageTool (офлайн-движок)

```bash
cd spellcheck
docker compose up -d
# Первый запуск скачивает образ (~1 ГБ). Проверка:
curl "http://localhost:8010/v2/languages"   # -> список языков
```

### 2. Бэкенд (Flask)

```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python app.py            # http://localhost:5001
```

### 3. Фронтенд (React)

```bash
cd frontend
npm install
npm run dev              # http://localhost:5173
```

Открыть **http://localhost:5173** — и всё готово.

> В демо-текст специально добавлены ошибки на двух языках, чтобы сразу увидеть
> работу подчёркиваний и попапа.

Если Docker недоступен, можно поднять **мок-движок** — несколько правил на
регулярных выражениях в схеме LanguageTool. Это не настоящая проверка, но

```bash
cd backend && source .venv/bin/activate
python ../dev-tools/mock_languagetool.py   # слушает :8010
# затем backend и frontend как обычно
```

## API

Базовый адрес: `http://localhost:5001`.

### `POST /api/check`
Проверить текст.

```jsonc
// запрос
{ "text": "На руском языке", "language": "auto", "enableStyle": false }
```
`language`: `"auto"` | `"ru-RU"` | `"en-US"`.

```jsonc
// ответ
{
  "language": { "code": "ru-RU", "name": "Russian" },
  "matches": [
    {
      "offset": 3, "length": 6,           // позиция ошибки в тексте
      "type": "spelling",                  // spelling | grammar | punctuation | style
      "message": "Возможная орфографическая ошибка.",
      "shortMessage": "Орфография",
      "replacements": ["русском"],         // варианты исправления
      "rule": { "id": "MORFOLOGIK_RULE_RU_RU", "category": "Орфография" },
      "context": { "text": "…", "offset": 3, "length": 6 }
    }
  ]
}
```

Если LanguageTool недоступен — `503` с подсказкой, как его запустить.

### `GET /api/dictionary` → `{ "words": [...] }`
### `POST /api/dictionary` `{ "word": "Kubernetes" }` → обновлённый список
### `DELETE /api/dictionary/<word>` → обновлённый список
### `GET /api/health` → `{ "languagetool": true|false, ... }`

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `LT_URL` | `http://localhost:8010` | Адрес LanguageTool. Для облака: `https://api.languagetool.org` |

| `MAX_TEXT_LEN` | `40000` | Лимит длины текста |
| `PORT` | `5001` | Порт Flask (5000 на macOS занят AirPlay) |

## Как это устроено

- **Подчёркивание как в Google Docs.** Редактор — это `<textarea>` поверх
  «подложки» (`div`) с идентичными метриками текста. В подложке ошибки обёрнуты
  в `<mark>` с волнистым подчёркиванием (цвет линии не зависит от прозрачного
  текста). Клик по подчёркнутому слову определяет ошибку по позиции каретки и
  открывает попап. Подробности — в [`Editor.jsx`](frontend/src/components/Editor.jsx).
- **Принять / отклонить.** Принятие подставляет вариант в текст и мгновенно
  сдвигает остальные ошибки; отклонение прячет ошибку (по правилу + слову).
- **Словарь исключений** фильтрует только орфографические ошибки: грамматика и
  пунктуация для «известных» слов остаются. Логика — в
  [`processing.py`](backend/processing.py).
- **Тумблер стиля** управляет параметром `disabledCategories` LanguageTool
  и режимом `picky`.

## Продакшн-заметки

- **N-граммы.** Для лучшего распознавания «спутанных» слов (their/there, то/-то)
  скачайте [n-gram данные](https://dev.languagetool.org/finding-errors-using-n-gram-data)
  и подключите том в `docker-compose.yml` (закомментированный блок).
- **Сборка фронтенда:** `npm run build` → статика в `frontend/dist/`, которую
  можно отдавать любым веб-сервером или через Flask.
- **Масштабирование словаря.** Сейчас словарь — общий JSON-файл. Для нескольких
  пользователей вынесите его в БД с привязкой к пользователю/проекту (интерфейс
  `UserDictionary` для этого изолирован).
