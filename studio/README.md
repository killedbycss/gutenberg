# Студия — четыре инструмента в одном окне

Объединяет модули **Орфография**, **Типограф**, **Конвертер** и **Макеты**
(генерация макетов по назначению из метрик шрифта) в одном окне браузера с
переключением по вкладкам-воркспейсам (как в Blender). Всё работает из одного
процесса на одном порту.

```
┌────────────────────────────────────────────────────────────────────┐
│  С Студия  • Орфография ⌘1  • Типограф ⌘2  • Конвертер ⌘3  • Макеты ⌘4 │  ← вкладки
├────────────────────────────────────────────────────────────────────┤
│                                                                    │
│                  (интерфейс активного модуля)                      │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘
```

- Переключение: клик по вкладке или **Alt+1 … Alt+4** (⌥1…⌥4 на Mac).
- Состояние каждого модуля сохраняется при переключении (ничего не сбрасывается).
- Кнопка **↗ Отдельно** открывает активный модуль в отдельной вкладке браузера.

## Быстрый старт (этот компьютер)

Дважды кликните по значку **`Гутенберг`** (`studio/Гутенберг.app`).
Его можно перетащить в Dock или на рабочий стол как обычный ярлык.

### Как поставить свою иконку на ярлык

Самый простой способ на macOS — подготовить квадратный PNG (лучше 1024×1024),
открыть его в «Просмотре», нажать `⌘A`, затем `⌘C`. После этого выберите
`studio/Гутенберг.app` в Finder, нажмите `⌘I`, кликните по маленькой
иконке приложения в левом верхнем углу окна информации и нажмите `⌘V`.
Перетащите именно `.app` в Dock или создайте его псевдоним через
**Файл → Создать псевдоним**: у файла `start.command` собственная иконка приложения
не сохраняется. Если Finder показывает старую картинку, удалите прежний значок из
Dock и перетащите приложение туда заново (иногда также помогает перезапуск Finder).

- Студия ещё не запущена → ярлык откроет Терминал, поднимет сервер и сам откроет браузер.
- Уже запущена → ярлык просто откроет вкладку браузера.

Под капотом ярлык вызывает **`studio/start.command`** (его можно запускать и
напрямую). Скрипт создаёт окружение Python (`studio/.venv`), при необходимости
собирает интерфейсы (нужен Node.js) и запускает сервер на `http://127.0.0.1:8770`.

Чтобы остановить — закройте окно Терминала или нажмите `Ctrl+C`.

> **Первый запуск, предупреждение macOS.** Если система пишет, что приложение/файл
> от «неустановленного разработчика», кликните по нему **правой кнопкой → Открыть →
> Открыть**. Это нужно один раз (и для `Гутенберг.app`, и для `start.command`).

> **Если браузер не открылся сам** — откройте вручную **http://127.0.0.1:8770**
> (именно `127.0.0.1`, а не `localhost`: на macOS `localhost` иногда уходит в IPv6,
> и страница не грузится). В окне Терминала эта ссылка тоже показана — по ней можно
> кликнуть, удерживая ⌘.

### Что должно быть установлено
- **Python 3** — обязательно. Скачать: <https://www.python.org/downloads/>.
- **Node.js** — нужен только чтобы **собрать** интерфейсы. Если папка
  `studio/build/` уже есть (например, её прислали вместе с проектом) — Node не нужен.
  Скачать при необходимости: <https://nodejs.org>.
- Интернет — только при самом первом запуске (чтобы скачать зависимости Python).

## Проверка орфографии (LanguageTool) — онлайн

Модуль **Орфография** работает на **LanguageTool онлайн** — ничего ставить не нужно
(**ни Docker, ни Java**), «словарь» подгружается онлайн, нужен только **интернет**.
По умолчанию используется публичный сервис `api.languagetool.org` (есть лимиты по
объёму — для обычной вычитки хватает).

- Нужна приватность или офлайн? Поднимите свой сервер LanguageTool и укажите адрес:
  `LT_URL=http://localhost:8010 studio/start.command` — тогда текст не уходит наружу.
- «Типограф», «Конвертер» и «Макеты» работают и без интернета.

📄 Подробности — **`spellcheck/LANGUAGETOOL.md`**.

## Как передать проект на другой Mac

На целевом компьютере достаточно **Python 3**, если вы приложите уже собранные
интерфейсы (`studio/build/`). Node там не понадобится.

### Вариант 1. Автоматически (рекомендую)

Дважды кликните **`studio/share.command`** — он соберёт интерфейсы и создаст на
Рабочем столе архив `Студия-ГГГГММДД.zip` без лишних тяжёлых папок
(`node_modules`, виртуальные окружения, кеши).

### Вариант 2. Вручную

В Терминале, из **корневой папки** проекта (`fonts`):

```bash
zip -r -X ~/Desktop/Студия.zip . \
  -x '*/node_modules/*' -x '*/.venv/*' -x '*/venv/*' \
  -x '*/__pycache__/*' -x '*.pyc' -x '*/.pytest_cache/*' \
  -x '*/dist/*' -x '*/.DS_Store' -x '*/.git/*'
```

> Важно: **не** копируйте папки `node_modules` и виртуальные окружения (`.venv`,
> `venv` и т.п.) — они тяжёлые и привязаны к конкретному компьютеру. Скрипт и
> команда выше их исключают. Папку `studio/build/` наоборот **включите** — тогда
> на другом Mac не нужен Node.

### На целевом Mac
1. Распакуйте архив в любую папку.
2. Дважды кликните `studio/start.command` (при первом запуске — правый клик → Открыть).
3. Готово — откроется `http://127.0.0.1:8770`.

## Настройки и устранение неполадок

| Задача | Что сделать |
|---|---|
| Сменить порт | Запуск с другим портом: `PORT=9000 studio/start.command` (или задать `PORT` в окружении) |
| Пересобрать интерфейсы | `bash studio/build.sh` (нужен Node) |
| Сбросить окружение Python | Удалить папку `studio/.venv` и запустить заново |
| «Порт занят» | Другой процесс занял порт — закройте его или запустите с другим `PORT` |
| «command not found: python3» | Установите Python 3 с python.org и перезапустите |
| Проверка орфографии не работает | Это нормально без LanguageTool — см. раздел выше |

## Как это устроено (кратко)

- `studio/backend/app.py` — единый сервер. Четыре существующих бэкенда
  (`spellcheck` / `typograph` / `converter` / `layouts`) импортируются **как
  есть** и монтируются под префиксами `/spellcheck`, `/typograph`, `/converter`,
  `/layouts`. Он же отдаёт оболочку и собранные интерфейсы. Слушает localhost и
  по IPv4, и по IPv6 — чтобы `http://localhost:8770` открывался в любом браузере.
- `studio/shell/index.html` — оболочка с верхними вкладками и четырьмя `iframe`.
- `studio/build/<модуль>/` — собранные интерфейсы модулей (создаёт `build.sh`).
- Исходный код модулей не дублируется. Каждый модуль по-прежнему можно запускать
  и по отдельности (см. README внутри соответствующей папки).

Порт по умолчанию — **8770** (порты 5000 и 7000 на macOS заняты AirPlay).
