# Типограф · RU / EN

Модуль типографических правок текста для русского и английского языков.
Бэкенд на Flask разбирает текст и возвращает исправленный вариант вместе со
списком правок и их позициями; фронтенд на React показывает результат с
подсветкой и даёт отменять правки по одной.

## Что умеет

| Тип | Русский | Английский |
|-----|---------|------------|
| **Кавычки** | `"…"` → `«…»`, вложенные → `„…“` | `"…"` → `“…”`, вложенные → `‘…’` |
| **Апострофы** | `д'Артаньян` → `д’Артаньян` | `don't` → `don’t`, `dogs'` → `dogs’` |
| **Тире — диалог** | `- Реплика` → `— Реплика` | — (чтобы не ломать списки) |
| **Тире — разрыв мысли** | `слово - слово` → `слово — слово` | US: `word—word` · UK: `word – word` |
| **Тире — диапазон** | `1990-2000` → `1990–2000` | то же |
| **NBSP — короткие слова** | `в лес` → `в·лес` (1–2 буквы) | `a city` → `a·city` (только `a`/`I`) |
| **NBSP — инициалы** | `А. С. Пушкин` → `А.·С.·Пушкин` | `J. R. Tolkien` → `J.·R.·Tolkien` |
| **NBSP — перед тире** | `слово·— слово` | `word·– word` (UK) |

- **Автоопределение языка** пофрагментно: язык кавычек берётся из их
  содержимого, язык тире и пробелов — из окружающего предложения. Смешанный
  RU/EN текст в одном фрагменте обрабатывается корректно.
- **Составные слова и даты не трогаются**: `какой-то`, `well-known`,
  ISO-даты `2020-01-01`, телефоны `8-800-555`.
- **Словарь исключений**: фрагменты, которые нельзя менять (напр. `C++`,
  бренды). Хранится в браузере (localStorage) и передаётся с каждым запросом.
- **Стиль тире в английском** переключается: US (em dash без пробелов,
  Chicago) или UK (en dash с пробелами, Oxford).

## Запуск

Нужен **два** процесса: бэкенд (порт 5050) и фронтенд (порт 5173).
Порт 5000 на macOS занят AirPlay/ControlCenter, поэтому используется 5050.

### 1. Бэкенд

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py                 # http://127.0.0.1:5050
```

### 2. Фронтенд

```bash
cd frontend
npm install
npm run dev                   # http://localhost:5173
```

Vite проксирует `/api` на бэкенд, так что CORS в разработке не нужен
(в API он всё равно включён — на случай раздельного хостинга).

### Тесты

```bash
cd backend
python tests/test_typography.py       # или: python -m pytest
```

## API

### `POST /api/correct`

Запрос:

```json
{
  "text": "Он сказал \"привет\" в 1990-2000.",
  "enabled_types": ["quotes", "dashes", "nbsp"],
  "en_dash_style": "us",
  "exceptions": ["C++", "\"Best-1990\""],
  "default_lang": "ru"
}
```

Ответ:

```json
{
  "original": "…",
  "result": "Он сказал «привет» в 1990–2000.",
  "count": 4,
  "edits": [
    {
      "id": 0,
      "start": 2, "end": 3,
      "original": " ", "new": " ",
      "rule_type": "nbsp", "rule": "short_word_nbsp",
      "message": "Неразрывный пробел после короткого слова",
      "lang": "ru"
    }
  ]
}
```

`start`/`end` — координаты правки в **итоговом** тексте (`result`), так что
фронт подсвечивает `result.slice(start, end)`. `original` — что было на этом
месте, для отката. Правки не пересекаются и отсортированы по `start`.

### `GET /api/rules`

Метаданные типов правок (для чекбоксов) и список включённых по умолчанию.

## Как устроен движок

Каждое правило — это проход по текущему тексту, возвращающий список замен.
Движок применяет проходы по очереди (порядок задан в `rules/__init__.py`),
пересчитывая координаты ранее найденных правок. Для каждой правки
сохраняется её диапазон и в исходном тексте — по нему в конце сливаются
пересекающиеся правки (например, когда «NBSP перед тире» затрагивает пробел
рядом с расставленным тире). Итог — набор непересекающихся правок с
корректными координатами в результате и корректным `original` для undo.
Инварианты закреплены тестами `test_edits_never_overlap_and_map_to_result` и
`test_undo_reconstructs_by_original`.

## Добавление нового языка

Ядро (`engine.py`) не привязано к RU/EN. Чтобы добавить язык:

1. Научить `language.detect_lang` различать его алфавит.
2. Добавить правила (или расширить существующие) с нужным `langs` и
   зарегистрировать их в `REGISTRY`.
3. При необходимости — свои глифы кавычек в `quotes.QUOTE_GLYPHS`.

Порядок проходов и работа с координатами при этом не меняются.
